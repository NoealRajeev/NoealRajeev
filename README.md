I'm **Noeal Rajeev Thaleeparambil**, co-founder and CTO of **BreaktroughF1 LLP**, a product engineering company from Kerala, India. I lead engineering across our products, from full-stack web platforms and immersive AR/VR experiences to IoT hardware and network security. I'm doing this while finishing my B.Tech in Computer Science and Engineering (IoT) at CHRIST University, Bengaluru.

### What I work on
- **Architecture and full-stack product engineering**: Next.js, TypeScript, Prisma and PostgreSQL platforms with shared, reusable core modules
- **IoT and embedded systems**: ESP32 mesh networks, sensor fusion, edge inference and MQTT integration
- **AR/VR**: immersive 3D campus navigation (UniView) and the open-source [`flutter_ar_vr`](https://github.com/Breaktroughf1/flutter_ar_vr) plugin
- **Network security**: ML-assisted traffic analysis and monitoring on embedded firewall hardware
- **Research**: applied IoT and machine learning work, listed on [Google Scholar](https://scholar.google.com/citations?user=HCES4OoAAAAJ&hl=en) and [ORCID](https://orcid.org/0009-0005-8170-1419)
